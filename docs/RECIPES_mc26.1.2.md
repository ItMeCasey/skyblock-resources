# Recipes for other mods: 26.1.2 (NeoForge; Forge)

Files: `common/data/skyblock_resources/recipe/{plants,compat}/<modid>/...`, shared by every 26.1.2 build and (unless a version folder overrides or deletes a file) by the older versions too. Same rules as `PLANT_RECIPE_RULES.md`. This file only covers the 2026-11-04 gap fill; the earlier 26.1.2 files (Biomes O' Plenty, Croptopia, Ecologics, EvilCraft, Forbidden Arcanus, Integrated Dynamics, Mystical Agriculture, Nature's Spirit, Occultism and the compat blocks) were not touched.

## Method

- Scratch copy of `versions/mc26.1.2/neoforge` under `%LOCALAPPDATA%\Temp\skyres-scan-gaps\nf262` (repo project untouched, no `eula.txt` touched). The scanner from the 1.21.1 NeoForge work was ported to the 26.1.2 API (`Identifier`, `VegetationBlock` instead of `BushBlock`, `lookupOrThrow`) and run on the `gameTestServer` type.
- Mods loaded (NeoForge 26.1.2): Regions Unexplored 0.7.0+beta4 (Modrinth `CgLkBfwk`, + Lithostitched), The Undergarden 0.9.8 (Modrinth `e8zLw9Sq`), Twilight Forest 4.9.3850 (CurseForge file 9417882), Allthemodium 4.2.0 (CurseForge file 9120636) with All The Ores 4.0.4 (CurseForge file 8023670, a required dependency of Allthemodium), on top of the project's existing test mods.
- Twilight Forest has no official Modrinth project (the `twilightforest` slug returns 404). CurseForge's public file list (`https://www.curseforge.com/api/v1/mods/227639/files`, no key) was used instead. Allthemodium's Modrinth project only has the 1.21.1 jar 3.0.1.
- Generated by the same script as the 1.21.1 work (scratch `gen2.py`), then checked: no air, no zero amounts, first drop equals `outputs`, every non-`minecraft` drop mod in the conditions, no duplicate recipe key over `common/`. Kapok and the small oak were scanned again with the pattern and thick soil options described in `RECIPES_mc1.21.1.md`.

## Forge 26.1.2

- Only Biomes O' Plenty and Oh The Trees You'll Grow have a Forge 26.1.2 build in `MOD_MATRIX.md`. The BOP recipes in `common/` came from the NeoForge build 26.1.2.0.21; the Forge build 26.1.2.0.22 (the one the Forge project loads) was compared file by file: all 1849 `data/biomesoplenty/**` JSON files (loot tables, tags, recipes, worldgen) are byte-identical to the NeoForge jar. The `common/` BOP recipes are therefore valid for Forge and no `overrides/26.1.2-forge` folder is needed.
- Regions Unexplored, The Undergarden, Twilight Forest and Allthemodium have no Forge 26.1.2 builds (CurseForge and Modrinth list only NeoForge). The new files are inert on Forge.

## Effects on older versions (`common/` is shared)

The new files name items that older builds may lack, which would break recipe parsing when the mod is loaded. Every new file was checked against the scanned item registry of each older target and `.delete` markers were added where an item is missing and the folder has no override with the same path:

- `overrides/1.21.1-neoforge`: 1 marker (Undergarden `twistybush`).
- `overrides/1.21.1-forge`: 10 markers (RU `salmon_poppy`, sky, lavender and salmon wisteria).
- `overrides/1.20.1`: 21 markers (RU `salmon_poppy` and the three wisterias, Undergarden `puff_mushroom` and `twistybush`, Allthemodium's three saplings). Forge and NeoForge 1.20.1 share this folder.
